# Evaluation corpus

Do not commit real-person photographs. Use a private, consented set with 2-30 photos per series, independent human best picks, series type, and separate calibration and holdout splits.

Target top-3 overlap >=85% across >=50 held-out real series (currently unmeasured). For two-photo bursts report top-1 agreement separately. Record group-face mismatches, eye errors, failures, processing time, and memory.
